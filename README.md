## About

Hi, I'm **Mohammad Sadegh Abiat**.

This repository is my journey of learning **OpenGL with C++**.  
I created this project while studying computer graphics, game development, and low-level programming.

The goal of this repository is to understand how modern graphics programming works by building things from the ground up using:

- C++
- OpenGL
- GLFW
- GLAD
- CMake
- GLSL shaders

Instead of using a game engine, this project focuses on learning the fundamentals behind rendering, shaders, buffers, and the graphics pipeline.
